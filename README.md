# Recallia

Recallia is a personal memory companion that helps you remember,
connect, understand, and rediscover your digital life.

## Core idea

> You don't need to remember where you saved something.
> Recallia remembers for you.

## Architecture

Recallia uses:

- Flutter
- Node.js
- TypeScript
- Fastify
- PostgreSQL
- Drizzle
- RabbitMQ
- S3-compatible object storage
- pgvector
- Docker

## Development

Recallia is built as a local-first mobile application with
domain-oriented backend services.
